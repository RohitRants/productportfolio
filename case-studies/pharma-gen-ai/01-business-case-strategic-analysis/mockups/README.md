# Screen Walkthrough

Once the prototype is built from [lovable-prompt.md](../lovable-prompt.md), export or screenshot each of the six screens and drop them here as `01-new-analysis.png` through `06-draft-business-case.png`, then replace this file with a short walkthrough like:

```
## 1. New Analysis
![New Analysis](./01-new-analysis.png)
Analyst starts a new business case with basic deal parameters.

## 2. Research Findings
![Research Findings](./02-research-findings.png)
Research Agent output — every row requires explicit analyst sign-off before continuing.

...
```

Keeping screenshots next to the narrative (rather than a separate slide deck) means a reviewer can see the human-in-the-loop design decisions directly, in context.
