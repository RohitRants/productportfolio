# Before you commit README.md

Search for `{{` in the file. Every token must be replaced:

| Token | What goes there |
|---|---|
| EVAL_PATH | repo path of the eval folder (4 uses; same path everywhere) |
| PHARMA_LOVABLE_URL | live URL, opened and confirmed loading today |
| RETAIL_DEMO_OR_IN_PROGRESS | live link, or the words "In progress" |
| TECHRISK_DEMO_OR_IN_PROGRESS | live link, or the words "In progress" |
| TEAM_SIZE, STAKEHOLDER_GROUPS, CADENCE | real numbers you can defend in an interview |
| ONE_OUTCOME_WITH_BEFORE_AND_AFTER_NUMBER | one result you influenced, with before and after |
| WHY_AI_PM_ONE_SENTENCE_IN_YOUR_OWN_WORDS | your real reason; delete if you can't write it honestly |
